# 1.1.2 archive

Frozen copy of Ashtonite.Core Drone as shipped for 1.1.2, the last version before the 2.0.0 rewrite.
It's byte-identical to the file that was on `main` before 2.0.0.

Don't use this as the live Behaviors file unless you need to roll back. To roll back, rename it to
`Ashtonite.Core Drone.Luau`. 2.0.0 uses the same saved-setting keys.
