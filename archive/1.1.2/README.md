Frozen copy of Ashtonite.Core Drone as shipped for 1.1.2, the last version before the 2.0.0 rewrite:
[`Ashtonite.Core Drone-1.1.2.Luau`](Ashtonite.Core%20Drone-1.1.2.Luau). It's byte-identical to the file that was on
`main` before 2.0.0 (commit `dc53a20`, 69,889 bytes, SHA-256 `9da3aa72acfe4d3a1e6afcfe541dffc855b4f20191cf8b3a5f44aa3173103fb0`).

`Ashtonite.Core Drone.Luau`. 2.0.0 uses the same saved-setting keys.
